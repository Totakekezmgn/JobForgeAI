# CODEX.md — Codex作業ルール

最終更新: 2026-06-17

あなた(Codex)はJobForge AIの実装担当である。設計はSPEC.md、タスクはTASKS.mdを正とする。
設計判断はあなたの役割ではない。仕様の曖昧さを発見したら実装せず報告する。

## 作業の進め方

- 1回の作業では**1チケットだけ**実装する(TASKS.mdのID単位)
- 実装前に、チケットの「対象」に書かれた関連ファイルを必ず読む
- 出力は**変更ファイルの差分(diff)のみ**。無関係な整形・リネームを混ぜない
- 実装後に `npm run build` を実行する。lintスクリプトがあれば `npm run lint` も実行する
- 変更したファイル一覧と、TASKS.md / CHANGELOG.md の更新案を最後に出す
- ビルドが通らない状態で作業を終えない。通せない場合は理由と現状を報告する

## 禁止事項(違反は差し戻し)

- SPEC.mdに反する実装(特に「個人情報最小化」「検証分離」「未ログインでも動く」「コスト上限主義」の4制約)
- `lib/serverAuth.ts` / `lib/authFetch.ts` / RLS関連の認証ロジックの変更・緩和・バイパス
  (チケットで明示的に指示された場合のみ可)
- クライアントから送られたuserIdを信用する実装
- APIキー・シークレット・個人情報のコード直書き、および .env系ファイルの変更・出力
- console.log等のログにES本文・面接回答全文・メールアドレス・検索結果全文を出す実装
- 新しいnpmパッケージの追加(必要なら理由を添えて提案のみ行い、人間の承認を待つ)
- 既存UI・既存機能を壊す変更(既存の動作を変える場合はチケットに明記されている時のみ)
- localStorageキー名・選考ステータス名の変更(SPEC.md 5章が正)
- Stripe本番モードの有効化、デプロイの実行
- 「あとで直す」前提の危険な実装・TODOで認証を飛ばす実装
- pricingや画面上に「無制限」という文言を追加する実装
- `live-company-research` を無料・無制限・ノーキャッシュで実行可能にする実装

## AI/外部APIルート実装の必須ゲート

AI/外部API系ルートを実装・修正する場合は、必ず以下を通す。

1. `getVerifiedUser(request)` による本人確認
2. `validate` による入力長・形式検証
3. `checkRateLimit` による短時間連打防止
4. `checkAndCountUsage` または同等のクレジット消費処理
5. 外部API実行
6. usage_eventsへの記録
7. 本文・回答全文・検索結果全文をログに出さないエラーハンドリング

上記の関数や引数が現状存在しない場合は、勝手に大規模実装せず、TASKS.mdの該当チケット範囲内で最小変更を提案する。

## live-company-research 実装ルール

- Tavily Basic Searchを初期値にする
- Advanced Search / Extract / Crawl は有料クレジット時のみ許可
- 無料ユーザーは月3回まで
- `companyName + date + searchDepth + queryHash` でキャッシュする
- キャッシュヒット時はTavilyを叩かない
- OpenAIに渡す検索結果は必要項目だけに絞る
- 1回の最大token・最大URL数を制限する
- 失敗時も外部APIが実行済みならusage_eventsに記録する

## 実装スタイル

- 既存コードの命名・構成・CSSクラス(globals.css)に合わせる。新規CSSは既存クラスで表現できない時のみ追加
- コメントは日本語で「なぜそうするか」を書く(whatの逐語訳コメントは不要)
- エラーは握りつぶさない。ユーザーに見えるメッセージは日本語で統一文言
  - 未ログイン時:「ログインが必要です。/login からログインしてください。」
  - 無料枠超過時:「本日の無料利用枠を使い切りました。クレジットを購入すると続けて利用できます。」
  - レート制限時:「短時間に連続して実行されています。少し時間を置いて再度お試しください。」
- AI呼び出しを追加する場合は validate.ts の入力検証と checkAndCountUsage の無料枠/クレジット消費を必ず通す
